# dotfiles

An archive of an Arch Linux desktop setup. Nothing in this repository is deployed to any machine.

The live configuration is generated by Home Manager in the [`Bad3r/nixos`](https://github.com/Bad3r/nixos) flake.
Shell, editor, terminal, window manager, launcher and theming come from there, and Home Manager writes its user
units into `~/.config/systemd/user`. Edit the flake and rebuild; a change made here reaches nothing.

## What is left

Archive material. NixOS does not read any of it.

- `.local/` - user scripts from the Arch setup: `sss-*` media, conversion and screenshot helpers, `rofi_run` and the
  `i3-*` window helpers, the pacman wrappers `sss-pacinstall`, `sss-pacrm`, `update-keys` and
  `pacman-update-check.abs`, plus `edit-kernel-params` and `verify-kernel-params`. Most call `pacman`, `yay` or X11
  tools, so they do not run on NixOS as written. `.local/share/fonts/awe6/` holds a Font Awesome 6 drop.
- `etc/` - system files for that machine. `etc/kernel/cmdline.d/*.conf` splits the kernel command line by category
  (graphics, performance, IPv6, storage, system) and `etc/kernel/install.d/85-cmdline-d.install` concatenates the
  fragments into `/etc/kernel/cmdline` during kernel install. The rest is Arch system configuration: pacman and its
  hooks, NetworkManager, `resolv.conf` and systemd-resolved, firewalld, Xorg, containers, sysctl, `locale.conf`,
  reflector, xfce4 helpers, and three systemd units. NixOS sets all of this from the flake.
- `usr/` - udev rules, tmpfiles drop-ins, a session desktop file and a few standalone scripts.
- `opt/kiro/` - a copy of the Kiro editor's `product.json`.
- `i3/`, `dunst/`, `x11/`, `themes/`, `ASCII/` - the pre-Home-Manager i3 config with its toggle scripts, the Arch
  `dunstrc` and its icons, `xinitrc`, `xprofile`, `Xmodmap` and `Xresources`, color schemes and terminal art.
- `misc/protonVPN-port-forwarding/` - a ProtonVPN port-forwarding service with its helper scripts.
- `dockerfiles/`, `packages.txt` - a Fedora flatpak build image and the Arch package list.

## Submodules

- `Mullvad-iOS-MacOS-DNS-Profiles` -
  [`mullvad/encrypted-dns-profiles`](https://github.com/mullvad/encrypted-dns-profiles). Still in use: the profiles
  provision encrypted DNS on iOS and macOS devices directly, independent of any host configuration here, so this one
  is not archive material.
- `.i3sass` - [`budlabs/i3ass`](https://github.com/budlabs/i3ass), i3 helper utilities that went with the archived
  i3 setup.

Fetch both with `git submodule update --init --recursive`.
